# PNU crest

Original transparent PNG from Pusan National University's official identity page:

- https://www.pusan.ac.kr/eng/CMS/Contents/Contents.do?mCode=MN074
- https://www.pusan.ac.kr/_contents/eng/_Img/Content/sym_pic1.png

`pnu-crest.png` is the original image. `favicon.png` (32×32) and
`apple-touch-icon.png` (180×180) are resized copies.

`pnu-favicon-v3.ico` wraps the 32×32 PNG in a standard ICO container.
Versioned icon URLs avoid reusing old resource cache entries. The root
`/favicon.ico`, `/apple-touch-icon.png`, and `/apple-touch-icon-precomposed.png`
routes also serve these icons.

The university publishes usage conditions and contact details at:
https://www.pusan.ac.kr/kor/CMS/Contents/Contents.do?mCode=MN236
